Fishtype

Fishtype プライバシーポリシー

制定日：2026年10月16日

「Fishtype」（以下「本アプリ」）は、MTP Works（以下「当方」）が提供する、釣った魚の写真に魚種名をタイポグラフィで乗せるアプリです。集める情報はできるだけ少なくしています。アカウント・位置情報・アクセス解析はありません。

1. 端末の中だけに残るもの

次のものは、お使いの端末の中だけに保存され、当方を含む外部に送信されることはありません。

  • 写真と、作った仕上がりの画像（最近の仕上がりは、アプリの領域に30枚まで残します）
  • 設定（魚種名の表記・言語）と、AI の判定に同意したかどうか
  • 判定した写真ごとの、AI が出した魚種名の候補。同じ写真を判定し直さないため、写真のファイルの指紋（SHA-256）と一緒に保存します。写真そのものは保存しません
  • Fishtype Pro の状態と、無料で判定できる残りの枚数

仕上がりの共有・保存は、あなたが「共有」「保存」を押したときだけ行います。

2. 魚種の判定（AI）

  • 送るとき: アプリで同意をいただいた後、作業中の写真についてだけ送ります。「今はしない」を選んだ場合は送りません
  • 送るもの: 写真を長い辺 1024 ピクセルまでの JPEG に描き直した写しです。アプリが写真を描き直すので、写しには撮影日時・場所・カメラなどの撮影データは付きません。当方のサーバーも、撮影データ（Exif）が残った写真は受け付けません。端末の地域が日本のときは「日本で釣った魚」という手がかりを添えます。端末の位置情報は使いません
  • 送り先: 当方のサーバー（Supabase・東京リージョン）を通して、Anthropic, PBC（米国）に送り、判定します。Anthropic が混雑・失敗したときだけ、代わりに OpenAI, L.L.C.（米国）に送ります。AI の会社が受け取るのは写真と当方の指示文だけで、端末ID は送りません
  • 保存: 当方のサーバーは写真を保存しません。Anthropic・OpenAI は、API で受け取ったデータを、初期設定ではモデルの学習に使わず、30日以内に削除すると定めています（規約違反の疑いがある場合は、より長く保存されることがあります）。詳しくは Anthropic のデータの保存期間・OpenAI の API のデータの扱いをご覧ください
  • 結果: AI が出した魚種名の候補をアプリに返して表示します。AI の結果は間違うことがあります

3. 当方のサーバーに残すもの

無料の判定の枚数を数え、購入を確かめるため、アプリは端末の中でランダムな端末ID（16進32桁）を作ります。端末ID は、氏名・メールアドレス・電話番号とは結び付いていません。iOS では、アプリを入れ直しても無料の枚数が戻らないよう、端末のキーチェーンに保存します。

当方のサーバーには、端末ID ごとに次のものを保存します。

  • 無料の判定に使った枚数（広告を見て足した分を含む）: 無料のお試しを取り直せないよう、削除のご依頼をいただくまで保存します
  • Fishtype Pro の日ごとの判定の枚数（1日30枚まで）: 30日で自動的に削除します
  • 購入の状態: 購入の鍵（Apple の取引の番号、または Google Play の購入トークンを SHA-256 で変換したもの）・商品・有効期限・テストの購入かどうか・最後に確かめた日時。期限が切れてから90日で自動的に削除します
  • 購入の確認を試した記録（不正の防止のため）: 1日で削除します
  • リワード広告の確認の記録: AdMob の取引の番号・広告ごとに作る使い捨ての合言葉・広告の枠。90日で削除します

当方のサーバーの動作の記録（ログ）に残すのは、端末ID の先頭8文字と、結果・プラン・商品・使った AI・かかった時間などの技術的な情報だけです。写真・AI の答え・購入トークン・鍵は記録しません。このほか、サーバーを提供する Supabase が、通常のリクエストの記録（リクエストのアドレス（AdMob からの広告の確認では端末ID を含みます）や IP アドレスなど）を、同社が定める一定の期間保存します。

4. 購入（Fishtype Pro）

支払いは Apple（App Store）または Google（Google Play）が行います。当方がカードなどの支払いの情報を受け取ることはありません。購入を確かめるため、アプリはストアの取引の情報を当方のサーバーに送り、サーバーが Apple・Google のサーバーに確かめて、第3条の購入の状態を保存します。

5. 広告（Google AdMob）

  • 無料でお使いの方は、短い動画の広告を見て、判定を1枚足すことができます。広告が出るのは「広告を見て1枚判定」を押したときだけです。バナー広告・全画面の広告はありません。Fishtype Pro の間は広告を出しません
  • 広告は Google AdMob（Google LLC）が配信します。AdMob の SDK は、広告の配信・効果の計測・不正の防止のため、広告の識別子・端末の情報・IP アドレス・広告の操作などの情報を集めます。詳しくは Google のサービスを使うアプリでの Google の情報の使い方をご覧ください
  • 広告の識別子: iOS では、追跡を許可するかを一度だけお聞きします。許可しない場合、広告の識別子（IDFA）は使われず、追跡に基づく広告の最適化は行われません。Android では広告 ID が使われます。端末の設定で、広告 ID のリセットや、パーソナライズされた広告の停止ができます
  • 欧州経済領域・英国・スイス: 先に Google の同意の画面を表示します。設定の「広告のプライバシーの選択」から、いつでも選び直せます
  • 報酬の確認: 報酬が正しいことを確かめるため、アプリは端末ID と、広告ごとに作る使い捨ての合言葉を AdMob に渡します。広告を見終わると、AdMob がこれを当方のサーバーに送ってきます。広告主には渡りません

6. アプリが使う権限

  • カメラ: 釣った魚の写真を撮るため
  • 写真: 選んだ写真を開くため、と仕上がりを保存するため（Android 10 以前では、保存に端末の保存領域の権限を使います）
  • トラッキング（iOS）: 第5条のとおり、広告のために一度だけお聞きします
  • インターネット: 魚種の判定・購入の確認・広告のため

Android では、購入と広告のライブラリが、動くために必要な権限も加えます（課金・広告 ID と Android の広告サービス・通信の状態の確認・短い間の端末のスリープの防止・短い裏側の処理）。

位置情報・連絡先・マイクなど、ほかの権限は使いません。

7. 第三者への提供

当方は、あなたの情報を販売しません。本ポリシーに書いたサービスの事業者（Supabase・Anthropic・OpenAI・Apple・Google、メールの転送の Cloudflare）に、書いた機能の提供のためにだけ渡します。法令にもとづく開示を求められた場合は、これに応じることがあります。

8. お子さまについて

本アプリは13歳未満のお子さまを対象としていません。13歳未満のお子さまの情報を、それと知りながら集めることはありません。

9. 選べること・データの削除

  • AI の判定を使わずに本アプリを使えます（「今はしない」を選び、魚種名を自分で入力できます）
  • 本アプリを削除すると、端末の中のものはすべて消えます（iOS では、端末ID はキーチェーンに残ります）
  • 当方のサーバーのデータの削除: 設定に表示される「サポート用の ID」を添えて、info@fishtype.app までご連絡ください（設定の「お問い合わせ」から送ると、ID がメールに入ります）。ご連絡から14日以内に、その端末ID のデータを削除します。削除すると、当方のサーバーの無料の判定の枚数と購入の状態も消えます。Fishtype Pro をお使いの場合は、アプリで「購入を復元」してください

10. お問い合わせいただいたとき

メールでお問い合わせいただいた場合（設定の「お問い合わせ」からを含みます）、メールアドレス・本文と、添えていただいたもの（アプリがメールに入れるサポート用の ID・アプリの版・OS など）を受け取ります。info@fishtype.app へのメールは、Cloudflare と Google（Gmail）を通して当方に転送されます。返信とご依頼への対応にだけ使い、それに必要な間だけ保存します。

11. ポリシーの改定

本ポリシーを改定する場合は、本ページで公表します。重要な変更がある場合は、アプリの中でもお知らせします。
